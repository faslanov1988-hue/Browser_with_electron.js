# Browser with electron.js
I did this browser with electron.js and chromeium this was fro only test but this browser is very good now it likes Opera browsers 




# Setup for developers
First we need to install all files of browser (main.js,preload.js,index.html,games.html,games).Then we need to install node.js we can install it from https://nodejs.org then open the installer and download the node.js then download web storm or VS code you can download VS code from microsoft store by searching VS code if oyu want to download better IDE you should open the https://www.jetbrains.com/webstorm/ the install it then open installer then install web storm then open web storm or VS code then create folder in the explorer then drop files to the folder then open this folder in webstorm or VS code then type npx electron . in terminal.Then browser opens automaticly,it may take a few second

First download the sNET v1.0.exe then open it then browser will opens,it may take a few minute
